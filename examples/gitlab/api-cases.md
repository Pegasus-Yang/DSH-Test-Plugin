# GitLab 接口用例模板

本文件是用户用例模板；准备脚本会填写占位参数，生成可以直接运行的 api.md。本节的接口用例只发送无认证 GET 请求，使用接口观察判断预期，不打开浏览器。固定标题来自准备种子，资源编号来自本次准备记录。

1. **用例名称：按专用名称检索项目**

   **原始用例**：通过项目搜索接口查找本次专用项目，检查数量和身份。

   **前置条件**：本次公开接口测试项目已准备完成。

   | 序号 | 操作步骤 | 预期结果 |
   | --- | --- | --- |
   | 1 | 发送 GET 到 ${project_search_url} | HTTP 状态码等于 200；响应数组长度等于 1；第一条的 id 等于 ${api_project_id}、path 等于 ${api_project_path}、visibility 等于 public |

   **收尾**：无；不修改项目或 Issue。

2. **用例名称：逐页读取 Issue，检查顺序和越界页**

   **原始用例**：按创建时间升序，每页读取一条 Issue，核对前三页并确认第四页为空。

   **前置条件**：本次项目按顺序准备了 alpha、beta、gamma 三条固定 Issue。

   | 序号 | 操作步骤 | 预期结果 |
   | --- | --- | --- |
   | 1 | 发送 GET 到 ${page_1_url} | HTTP 状态码等于 200；响应数组长度等于 1；第一条的 iid 等于 ${alpha_iid}、title 等于 ${alpha_title} |
   | 2 | 发送 GET 到 ${page_2_url} | HTTP 状态码等于 200；响应数组长度等于 1；第一条的 iid 等于 ${beta_iid}、title 等于 ${beta_title} |
   | 3 | 发送 GET 到 ${page_3_url} | HTTP 状态码等于 200；响应数组长度等于 1；第一条的 iid 等于 ${gamma_iid}、title 等于 ${gamma_title} |
   | 4 | 发送 GET 到 ${page_4_url} | HTTP 状态码等于 200；响应为长度 0 的空数组 |

   **收尾**：无；不修改项目或 Issue。

3. **用例名称：不存在的项目返回明确错误**

   **原始用例**：读取本次命名空间下不存在的专用项目，检查状态码和错误信息。

   **前置条件**：缺失项目的路径使用本次唯一标记，不创建这个项目。

   | 序号 | 操作步骤 | 预期结果 |
   | --- | --- | --- |
   | 1 | 发送 GET 到 ${missing_project_url} | HTTP 状态码等于 404；响应字段 message 等于 404 Project Not Found |

   **收尾**：无；不创建缺失的项目。
