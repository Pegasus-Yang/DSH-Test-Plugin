## 当前十二个工具

下表依据 Hub `src/runbridge_hub/mcp_server.py:126–214`。拟议 DSH 名称前缀为 `mcp__runbridge__`；名称相近不表示参数等价。

| 现有工具             | 当前作用                             | 插件接入用途                               |
| -------------------- | ------------------------------------ | ------------------------------------------ |
| `node_inspect`       | 查询许可内节点与资源                 | 已批准运行的启动前检查                     |
| `browser_start`      | 新建受管理 Chromium、Context、空白页 | 每用例实例的资源申请                       |
| `browser_sessions`   | 当前 grant 的活动 MCP 会话           | 启动响应丢失与中断诊断，仍需证明归属       |
| `browser_status`     | 会话状态、清理、页面 ID 和 URL       | 资源核对、选页、收尾复核                   |
| `browser_stop`       | 释放会话，等待清理报告               | 自动收尾及设置页恢复                       |
| `browser_navigate`   | HTTP(S) 导航及 DOM 就绪              | 有说明的导航动作                           |
| `browser_snapshot`   | URL、标题、最多 20000 字符语义快照   | 观察页面、选择定位                         |
| `browser_fill`       | 唯一输入元素的 fill                  | 有说明的逐字段填写                         |
| `browser_click`      | 唯一元素的普通点击                   | 有说明的点击动作                           |
| `browser_read`       | 可见文本或输入值，最多 20000 字符    | 基础实际值读取，检查 truncated             |
| `browser_wait_for`   | 元素状态、完整文本或输入值等待       | 有说明的业务等待，不能直接替代独立断言采集 |
| `browser_screenshot` | 当前视口 PNG，最多 2 MiB             | 报告截图与首期周期预览                     |

带页面的工具要求 `session_id`、`page_id`；`timeout_ms` 默认 10000，范围 1–30000，包含锁排队时间。`target` 支持 role、label、text、test_id、css，语义文本精确匹配，多个匹配拒绝猜测。没有 Playwright MCP 的 snapshot ref，也没有默认当前标签页。

## 与现有操作入口的差异

现有插件在[实际操作定义](../../../src/actual-operations.ts)和[原生测试流程](../../../src/native-test.ts)固定列出 `mcp__playwright__` 名称并做准入校验。

| Playwright MCP 操作或行为              | RunBridge 当前可用方式 | 缺口与处理                                               |
| -------------------------------------- | ---------------------- | -------------------------------------------------------- |
| `browser_navigate`                     | 同名，但补入会话和页面 | 可适配；保留当前步骤的 URL 来源限制                      |
| `browser_click`                        | `target` 定位替代 ref  | 可适配；不能直接把 ref 参数转为 CSS                      |
| `browser_type`                         | `browser_fill`         | fill 替换整个值；不能承诺逐键输入或 submit 行为等价      |
| `browser_wait_for`                     | target 与状态等待      | 与旧工具参数不同；等待超时记录失败，未命中不能充当实际值 |
| `browser_tabs` 列表                    | `browser_status.pages` | 可以观察并明确选页；创建和关闭页面未提供                 |
| `browser_close`                        | `browser_stop`         | 关闭整个本次会话，并核对 cleanup                         |
| `browser_press_key`、返回导航          | 无                     | 基于被批准用例增加独立原子工具                           |
| 选择框、复选框、hover、drag            | 无专门工具             | 点击可覆盖部分复选框场景，不能据此宣称其他控件行为完整   |
| Frame、dialog、上传、下载、resize      | 无公开首期工具         | 按实际回归覆盖范围分期补齐                               |
| `browser_evaluate`、`browser_run_code` | 无                     | 可信采集改为固定只读接口；常规交互继续原子操作           |
| `browser_take_screenshot`              | `browser_screenshot`   | 当前只截视口；没有 fullPage 参数                         |

规划阶段只提供所选后端确实支持的工具和限制。遇到缺失操作，明确 BLOCKED 或不支持；不能让模型假造工具、用截图猜通过、改预期或改走 DSH 本机浏览器。

## DOM 采集差异

现有[采集适配器](../../../src/adapters.ts)以固定 `domFunction` 在实际页面采集。计划及输出类型、原始文字检查点、断言比较程序可继续复用；浏览器数据生产者需要替换。

| 既有模式  | 当前合同                                           | 现有 RunBridge 覆盖                                              |
| --------- | -------------------------------------------------- | ---------------------------------------------------------------- |
| text      | DOM textContent 或指定属性，trim                   | read/text 使用 inner_text，不能保证同义                          |
| value     | 元素 value                                         | read/input_value 可覆盖常规输入，仍需确认控件与缺失值语义        |
| number    | 对文本或属性做既有格式校验再转数值                 | 可取得部分文本，再按原程序转换；属性缺口仍在                     |
| count     | CSS 匹配总数，允许 0                               | 缺失；唯一定位工具不能返回总数                                   |
| visible   | 缺失为 false，按 getClientRects 判断               | wait/visible 只会等待或超时，没有该实际值合同                    |
| url       | href 或 pathname                                   | snapshot/status 返回 URL，可在程序里解析；采集时点和来源必须一致 |
| attribute | 属性存在时保存，包括空字符串；href 可解析 pathname | 缺失                                                             |
| index     | 显式 0 起索引；未给索引的常规元素采集要求唯一      | 当前 target 不提供索引                                           |

推荐在 Hub 增加固定 `browser_capture(session_id, page_id, captures, allowed_origins, timeout_ms)`，返回 `values`、实际 `url`、`title` 和截断信息。captures 仅允许现有采集定义；不接收任意函数、表达式或脚本。Hub 在同一个工具操作锁内检查来源并完成本次批量采集，插件再次核对 URL 与输出 Schema。

首期如果完全不改 Hub，只能限定到现有读值能力，必须在计划冻结前说明采集覆盖范围。文本语义无法等价时，不应通过修改老用例的冻结预期来制造兼容。固定采集接口补齐后，使用同一页面夹具比较两个后端的实际采集值，包括隐藏文本、空白、空属性、0 匹配、多个匹配、显式索引和链接路径。

HTTP `test_api_get` 继续在 DSH 宿主发送请求，并不会因为换了浏览器后端而自动在虚拟机执行。虚拟机回环 `127.0.0.1` 与 DSH 宿主回环是不同地址；浏览器能访问的业务接口不一定能被现有 HTTP 采集访问。需要虚拟机网络内 API 的用例，应另行明确请求执行位置与授权范围，不能静默混用。

## 显示能力差异

当前[预览配置接入](../../../src/preview-setup.ts)只接受本机 stdio Playwright MCP，通过 initPage 生成本机 `.cdp`；[预览管理器](../../../src/preview.ts)只接受回环 Browscreen 地址。远程服务不能复用这套本机 CDP 初始化方式。

| 项目                 | 现有能力                                                                                | 对接要求                                           |
| -------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 浮窗和图片路由       | 现有[进度路由](../../../src/progress-access.ts)与[预览页](../../../src/preview-page.ts) | 保留展示入口，扩展数据来源与“周期截图”状态         |
| MCP 受管理浏览器画面 | 一次 screenshot 工具返回 PNG                                                            | 可先做周期刷新；图片受同会话操作锁影响             |
| Hub 独立 WS 画面     | 只支持 chrome-cdp 借用实例                                                              | 为 MCP 的受管理会话增加来源与页面映射              |
| 选页                 | Chrome target_id；202 只表示请求受理                                                    | 受管理 page_id 要有明确映射，首张新图才确认切换    |
| PNG 封包             | 4 字节长度、JSON 元数据、PNG                                                            | 先拆包，再核对来源和解码；不能把整个消息当成 PNG   |
| 时间与陈旧性         | Hub 单调时钟判断 5 秒陈旧                                                               | DSH 也清理失效图，不跨机器时钟相减计算延迟         |
| 视频与指针           | RunBridge 没有录制、回放、指针层                                                        | 远程选项按真实能力展示；不沿用本机“录像已开启”提示 |

持续来源优先探测 Hub 的已有 Page 与 CDP 截图；Node 专用回环 CDP 为备选。两条路线都需要确认同页、导航、关闭、锁等待、慢消费者和资源收尾；“公开 SDK 有接口”不足以证明当前跨机链路已支持。
