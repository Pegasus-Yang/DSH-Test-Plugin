# RunBridge MCP 远程浏览器对接

[文档导航](../../README.md) · [当前实现](../../architecture/当前实现.md)

目标是让 DSH 测试插件通过 RunBridge Hub 的 MCP 工具，在远程 Node 上启动专用浏览器、执行用户用例，并在现有浮窗中查看同一浏览器的运行画面。

**当前结论：可以对接，但现有服务不能直接等价替换 Playwright MCP。** 操作名称与参数、可信断言采集、会话释放和预览来源都需要适配。受管理浏览器目前提供 MCP 截图；独立画面流目前仅支持借用 Chrome。这两条链路必须统一到本次测试的同一会话和页面。

本目录是对接提案，尚未实现或进行 DSH 到虚拟机的端到端验收。现有行为与拟议改动分别说明，不以其他项目的验收代替本插件验收。
