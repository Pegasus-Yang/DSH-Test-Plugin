# RunBridge MCP 远程浏览器对接

[文档导航](../../README.md) · [当前实现](../../architecture/当前实现.md)

目标是让 DSH 测试插件通过 RunBridge Hub 的 MCP 工具，在远程 Node 上启动专用浏览器、执行用户用例，并在现有浮窗中查看同一浏览器的运行画面。

本目录保留接入前对 12 个工具及画面差异的历史提案。用户随后批准完整替代与持续画面，同时修改插件、Hub 和 Node；交付版本为插件 0.12.0、Hub/Node 0.5.0。

当前行为见[使用指南](../../user-guide/RunBridge远程浏览器与持续预览.md)与[远程架构](../../architecture/RunBridge远程执行与画面.md)，真实验证见[接入验收](../../project/RunBridge远程浏览器接入验收.md)。提案的源码哈希和 HTTP 记录保持原基线，不代表交付版本。

实际交付采用插件管理的私有 MCP 连接，复用公开 DSH 工具投影，并由 Hub 在同一 Page 上持续采集。替代范围为插件正常浏览器操作、可信采集与生命周期，不承诺 Playwright MCP 任意脚本、下载、网络拦截或全部 SDK 方法等价。
