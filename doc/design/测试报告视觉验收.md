## 五项视觉检查

- 字体：系统中文无衬线，正文 14px、步骤 14px、标题 18–23px；辅助标识使用较小字号，长标题可换行，没有省略关键步骤内容。
- 布局：浅色左导航、搜索用例列表、右侧详情；间距和细分隔线区分层级，移除原先大卡片纵向堆叠。窄视口改为纵向结构。
- 色彩：青色表示当前选中项，绿色通过、红色断言失败、琥珀色执行异常；状态同时有文字，不只依赖颜色。
- 图片与图标：Tabler 原始图标附 MIT 许可；页面截图全部来自实际运行证据，没有用设计稿示意网页充当证据。
- 文案与数据：总耗时明确包含规划，步骤耗时单独计算；通过率分母为全部实例，未执行断言不记为通过。保留取消、阻塞、结论不足等业务状态。

## 已验证交互

- 名称搜索、无结果提示、清除筛选；真实三行登录记录切换 valid / wrong / empty，详情与实际值同步变化。
- 数据集筛选到 empty 后显示 1/3，右侧选中实例自动更新；概览状态入口和表格能返回用例。
- 步骤、断言、附件页切换；断言“查看证据”定位对应附件；原始响应展开；截图放大与关闭。
- 静态文件离线打开；HTTP 报告在线查看；下载冻结计划时 Chrome 显示 plan.json 完成。
- 200% 浏览器缩放形成约 744 CSS 像素窄视口，导航和列表没有横向溢出。390px 手机视口尚未单独验收，本次主目标是桌面报告。
