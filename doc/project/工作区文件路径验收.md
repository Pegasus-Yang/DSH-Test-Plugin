# 工作区文件路径验收

> 发布记录：相关实现已纳入 0.11.0，见[版本发布验收](0.11.0版本发布验收.md)。以下保留实施阶段的版本、运行结果和未发布状态，不改写原始失败或验收事实。

验收日期：2026-10-06。包版本仍为 0.10.0，本次修复保存在主分支“未发布”，不创建版本标签。

## 问题与原因

把测试目录添加到 DSH 后，在该工作区的对话执行 `/test-run ui.json` 提示文件不存在；改用目录内绝对路径，又提示必须位于项目工作区。

实际文件存在。旧代码使用全局 `tests.config.workspace` 解析并检查路径；其默认值来自服务进程的 process.cwd()，不会随 DSH 对话工作区改变。相对路径在旧目录查找，绝对路径被同一个旧目录的边界检查拒绝。`/test-plan --file` 和 `/test-data` 也使用了同一全局目录。

公开 DSH SDK 0.2.1-alpha.1 的当前会话工作目录位于 `agent.session.header.cwd`。Header 是宿主验证、保存的只读元数据；命令从发起 Agent 获取，不接受命令参数额外传入工作区，也不从全部已添加目录中搜索同名文件。

## 修改范围

- 三个文件入口优先使用发起对话的 cwd；仅历史会话缺少 cwd 时回退到插件 workspace。
- 相对路径解析与绝对路径边界使用同一目录，继续检查 realpath、上级目录及符号链接逃逸。
- 不修改插件的全局 workspace，避免两个对话先后调用时串目录。
- `/test-run` 的缺失文件错误包含实际查找路径及工作区；越界错误注明允许目录。
- 同步发行 dist、使用说明、中英文 README、安装及故障文档、GitLab 指南与 changelog 未发布项。

outputRoot 和设置页高级处置证据仍沿用插件配置；此次不涉及收尾约束、日志或报告优化方案的实施。

## 自动回归

修改前运行新增场景，20 条命令检查有 5 条失败：相对 JSON、绝对 JSON、文字/CSV 入口、跨对话同名文件和当前目录边界。旧实现甚至会接受仍位于全局配置目录、却已越过当前对话目录的文件。

修复后：

| 检查 | 结果 |
| --- | --- |
| 命令路径与用例文件专项 | 32 / 32 通过；命令 20 条，输入文件 12 条 |
| 全部单元与集成测试 | 274 / 274 通过，25 个测试文件；其中原生执行集成 43 条 |
| 公开 SDK TypeScript 类型检查 | 通过 |
| 构建及发行入口检查 | 通过，源码生成的 dist/index.js 包含修复 |
| 源码与新增测试格式、Git 差异检查 | 通过 |

覆盖当前对话优先、相对与绝对路径、TXT/Markdown、原生审核及 CSV、带空格路径、不同工作区同名文件、缺失时不回退其他目录、外部绝对路径、上级路径、符号链接以及无 cwd 的历史会话。

macOS 临时目录 `/var` 与 `/private/var` 指向同一位置，测试预期按 realpath 归一化，不把有效工作区符号链接误判为越界。

## 实际输入文件读取

使用公开 SessionStore.prepare 创建带实际测试目录 cwd 的会话对象，调用构建后的插件命令处理器。读取用户提供的真实 ui.json，用原 parsePlan 校验完整计划：

| 输入 | 结果 |
| --- | --- |
| ui.json 相对路径 | 成功读取，4 条用例定义 |
| 同一 ui.json 的绝对路径 | 成功读取，与相对路径内容相同 |
| 读取前后文件 SHA-256 | 一致，原文件未修改 |
| 测试业务动作派发数 | 0 |

此检查替换测试启动入口，只验证命令解析、文件读取和计划合法性，未启动浏览器、未登录 GitLab、未执行这 4 条业务用例。不能把它当作当前用户服务中的完整 UI 验收。

解包后检查 128 个公开文件，未包含 .local、运行产物或依赖目录；按本地私有配置中的实际账号密码扫描，命中数为 0。此检查未输出敏感值，原输入文件继续保留在用户测试目录。

用户审核后，按[安装与运维的本地更新流程](../deployment/安装与运维.md#构建与打包)安装该包并重启原 profile。在 DSH 中进入目标测试目录所属对话，先试相对路径，再试目录内绝对路径。仅添加一个新工作区不会改变原对话的 cwd；应新建或打开目标工作区的对话。

如果仍提示缺失或越界，首先核对错误列出的工作区、实际查找路径和安装目录中的 dist/index.js；旧服务需要重新加载更新后的插件。保留原模型、MCP、输出目录与会话配置。
