## 自动发布行为

- 普通分支和 PR 执行现有回归；仅版本标签的 `push` 在 `compatibility` 汇总门禁成功后进入 `release`。
- 构建和三版宿主继续验证同一份 `candidate`。发布步骤核对摘要、标签、源码版本和包内版本，只复制并重命名该包，不重新打包。
- Release 资产为版本化 `.tgz` 及 `.tgz.sha256`，使用工作流的 `GITHUB_TOKEN`；只有发布作业申请 `contents: write`。预发布后缀标记为 prerelease。
- 使用 `gh release create --verify-tag --generate-notes`，已有同名 Release 时失败，不覆盖资产。具体操作及旧标签边界见[发布指南](../deployment/版本发布与Git标签.md#版本标签自动发布)。
