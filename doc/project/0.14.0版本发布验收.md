## 交付范围

按[配置优化方案](../design/配置展现与交互优化方案.md)实施，保留宿主侧私有访问 JSON 文件，不提供四项连接信息手工录入。新增完整模板、复制／下载入口、字段解释、无秘密解析摘要，以及 MCP 握手、工具清单和只读 `node_inspect` 检测。检测不分配浏览器，不解除隔离。

浏览器位置、连接及本机画面／录像使用同一草稿和一次原子保存；模式即时联动，关闭设置保留草稿，放弃恢复整份已保存设置。连接状态与保存状态、隔离状态分别展示；修改连接参数或宿主文件后撤销旧检测结论，取消／迟到结果不能覆盖新草稿。保存后下次运行生效，执行中的测试保持原连接。

连接优先展示，异常处置仍置顶；本机画面依赖按开关展开，空 MCP 列表提供真实指南和重新读取动作，命令与端口收在高级设置，校验失败定位字段。报告维护默认折叠，先读取并核对目标运行，再提供重建动作。中英文安装／使用指南、配置与故障排查、当前架构、版本入口和更新日志同步更新；历史验收及截图来源保留。

## 已知边界

- 只读 `node_inspect` 不返回实际 grant_id，不能证明文件标注的许可 ID 与令牌配套；真实会话身份仍在运行时校验。资源状态可能变化，检测通过不保证稍后分配或业务执行成功。
- 文件中的 expires_at 仅辅助提示，授权以 Hub 为准；不签发／续租许可，不增加四项凭据录入。
- 当前宿主未提供离开拦截 API，草稿按表单保留；整页确认刷新／离开后不持久保存。表单只有宿主公开的 writable／revision 状态，不能准确列出所有覆盖层的来源。
- 本轮验证基本字段关联、焦点及窄视口，不声称完整 WCAG 符合性；没有完成屏幕阅读器、200% 缩放与全部对比度测量。
- 远程录像、Windows、公网 TLS/NAT、容量与生产服务未纳入本轮新验收。
