## 支持范围与实现

`dsh-compatibility.json` 是支持集合和构建 SDK 的唯一维护来源。22 个 DSH peer 使用三个精确版本的联合范围，optional 属性保留；开发／构建 SDK 固定 alpha.3。没有新增运行时版本分支，也不在插件内链接或打包另一份宿主 SDK。其他 alpha、rc、正式版本不自动纳入支持集合。

增加显式 `compat:sync`、范围及开发基线检查、发行完整性检查和 18 项兼容回归。真实接口验收暴露通用数组指导缺失，将原先仅在 RunBridge 分支的 `.length` 指导移到共用位置，并明确 `unit` 只用于展示；已有严格比较、实际数组和固定预期保持原义。已有集成回归扩展覆盖同一响应的 iid、正文长度和空 labels，仍只采集一次。

GitLab 草稿用户样例补齐从列表点击原生 New item 打开弹窗的前置。取消后检查表单关闭、原列表路径和接口空数组；增加实际操作审计，拒绝取消后的补跳转。审计器绑定本用例 DOM 原始观测，支持同一实际值对应的合法断言写法；4 项正反例覆盖原生入口、绕过入口、额外导航和不可信关闭证明。

完整回归现为 **322 项单元 + 63 项集成，共 385 项**。受控模型验证支持环境凭据、显式分项补验模式和逐轮实际 Agent 空闲探针；生产预算保持原值。

## 真实模型与 GitLab Markdown 验收

各版使用独立 home、profile、工作区、MCP、浏览器和输出。核心场景与 GitLab 接口的可信结果来自下表，各轮继续前都有实际 Agent 空闲、作用域关闭和在途工具归零记录。

| 范围 | alpha.1 | alpha.2 | alpha.3 |
| --- | --- | --- | --- |
| Markdown UI、接口正向／固定反例、CSV PASS／FAIL | OpenCode 全部通过 | OpenCode 全部通过 | 前一 MiniMax 阶段全部通过 |
| 审核关闭修改／重新批准／取消、普通聊天、同会话下一轮、在途停止 | 全部通过 | 全部通过 | 全部通过 |
| GitLab Markdown API：项目检索、四页分页、缺失项目 | 3 条／21 项固定检查通过 | 3 条／21 项固定检查通过 | 3 条／21 项固定检查通过 |
| GitLab Markdown UI：组合筛选、草稿预览原生取消 | OpenCode 两条通过 | OpenCode 两条通过 | OpenCode 分项通过 |

用户指定的 `OPENCODE_API_HOST`／`OPENCODE_API_KEY` 以 OpenAI 兼容协议接入。服务端模型目录接受的精确 ID 为 `deepseek-v4.1-flash`，使用宿主内置 `opencode-go` 保留原生会话头，基路径补 `/v1`，不覆盖 route 级 `api`。API 密钥仅从环境读取，不写入 YAML、凭据副本、发行包或 Git。原始 SDK 请求记录证明实际提供方／模型；alpha.3 的核心和接口既有成功记录继续保留其实际 MiniMax 来源。

alpha.1／alpha.2 的核心与 API 来自 `dsh-0.13.0-opencode` 完整尝试，整轮各自保留 FAIL；UI 的合格补验为各自 `verified-ui-v5`，整体 PASS。alpha.3 筛选来自 `verified-ui-v5`，草稿、资源释放及卸载来自 `verified-draft-v7`，后者 PASS；前一 v5／v6 因校验器误报留下的 FAIL 不改写。所有单项摘要标明模式，不将 UI／草稿补验记为单次完整矩阵。

每条合格记录核对原会话执行／清理、认证 HTML、账本重放、冻结预期、原始观察、证据 SHA、离线桌面／窄屏、筛选与附件，以及实际步骤、手工导出与最终记录一致。固定反例与 CSV 中预期错误的实例保持 FAIL，作为正确拒绝的通过门禁。受控步骤／收尾／取消预算为 600000／180000／500 ms，整批等待 30 分钟、驱动外层 60 分钟，生产默认预算不变。

UI 后独立 GET 证明 closed／dsh-smoke 仍只有原 gamma，取消草稿检索为空数组。三版使用各自专用项目；仅发生只读及未提交草稿的重试在确认固定种子未变化后复用本版准备记录，相关基线回读单独保留。全部本轮专用项目最终按原记录校验归属后清理，并通过登录会话逐个确认 404。

## 原失败与修正

- 早期包对数组与数量比较形成真实 FAIL。共用指导修正后，用原固定种子和预期复验 21 项通过；严格比较保持不变。
- 模型曾改写草案引号，原生审核一致性守卫正确拒绝。MiniMax 后续 HTTP 429／2056 额度耗尽使必要场景中断，保留原轮次和隔离结果，按用户指定改用新服务。
- OpenCode alpha.1 直接打开新建页后 Cancel 实际回到 `/`，报告正确 FAIL。旧 alpha.3 虽有原始 PASS，但实际操作包含 Cancel 后补导航，重新审计判为不合格的取消语义证据。独立浏览器确认原生列表新建弹窗的行为后，补齐样例前置、保持原路径预期并加操作审计；新三版记录覆盖修正后的用户入口。
- 早期 `reasoning: off` 被目录拒绝；后续 TLS 建立前发生 ECONNRESET。最终不覆盖推理档位，仅在测试子进程的 NO_PROXY 中加入模型服务主机后稳定完成，不修改全局代理或宿主 SDK。错误探针显式混传 Undici dispatcher 的异常属于探针问题。
- 取消审计器最初过度限制断言写法，分别误拒 `visible false` 和 `neq true` 对应的实际 false。改为绑定本用例 DOM 观测，新增正反例复核；alpha.3 再以全新 profile 完成真实空闲及卸载，不靠离线复核补造生命周期事实。
- 修正 CSV 离线报告的分组选择器、普通聊天结束标点匹配及校验副本缺夹具等驱动问题。并行回归曾触及框架时限，最终 SDK 回归串行执行，不改生产预算或删除测试。CI 补上 MCP 自身匹配的 Chromium 安装。

## 旧宿主用户与交付边界

alpha.1～3 使用同一个 0.13.0 包、相同配置和安装方式，不需要版本豁免。推送前可安装本地最终 tgz；维护者审核并手动推送提交及标签后，使用 `github:Pegasus-Yang/DSH-Test-Plugin#v0.13.0`。正常停服、移除旧依赖、添加、重启同一 profile 并刷新浏览器，保留工作区、输出及偏好。具体步骤见[安装与运维](../deployment/安装与运维.md)。

不在支持集合内的宿主继续使用已验证的历史组合，或先验证新基线。历史 `v0.12.1` 声明 alpha.1，`v0.12.2`／`v0.12.3` 声明 alpha.3，均未声明 alpha.2。提高支持下限须记录实际不兼容原因、最后兼容标签和迁移方式，经用户审核。

本地 Git 来源安装验证发行快照的策略、入口和无豁免准入。GitHub Actions 新矩阵、远端标签一致性和远端固定标签安装须在用户手动推送后核对；本机验证不代表远端已运行。本轮未新增 RunBridge 实机、Browscreen 录像或其他操作系统的真实模型验收。
