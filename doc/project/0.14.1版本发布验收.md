RunBridge 私有访问文件同时支持 JSON 与带注释的 YAML，按内容识别，不依赖 .json、.yaml 或 .yml 后缀。设置读取、连接检测和实际运行共用解析及字段校验；旧 JSON 无需转换。继续使用宿主侧文件，不增加四项信息手工录入。

复用已有 yaml 2.8.1，将其从开发依赖移入运行依赖。保留 32 KiB 上限、必需字符串字段、URL 与令牌校验；YAML 采用 core 标量类型，注释不进入连接身份。YAML 解析拒绝语法错误、重复字段、多文档、自定义标签、循环别名及错误的顶层／字段类型，解析错误不回显配置原文。

## 边界与本地交付

- 本轮 YAML 支持仅用于 RunBridge 访问配置；没有增加 YAML 用例入口，用户用例继续使用 TXT、Markdown 与 CSV。
- 文件中的 expires_at 仅辅助提示，Hub 负责实际授权；只读节点检测不能提前证明 grant_id 配套或稍后分配成功，真实会话身份继续在运行时校验。
- 公网 TLS/NAT、生产服务、远程录像和完整无障碍审计不在本轮验收范围；页面基础交互及连接测试与生产确认分别记录。

代码、测试、dist 和当前文档纳入本地交付提交，附注标签 `v0.14.1` 指向该完成提交，目标 package.json 与运行 plugin_version 均为 0.14.1。使用 `git rev-parse 'v0.14.1^{commit}'` 查询交付提交。本轮不推送，远端标签和 GitHub 安装入口须由用户审核推送后另行确认。
