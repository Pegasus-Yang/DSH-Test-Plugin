## DSH 同包矩阵与真实模型

三个宿主均完成公开安装、同批 SDK、类型与确定性回归、Web 设置保存及重启读回、禁用／启用，以及受控模型和 GitLab Markdown UI／接口验证。每版使用独立 profile 和本轮独立准备的 GitLab 种子，不使用版本豁免，也不在插件 profile 安装第二份 DSH SDK。

| 宿主 | 确定性回归 | 受控模型与 GitLab | 最终验收相关宿主停止 |
| --- | --- | --- | --- |
| 0.2.1-alpha.1 | 393 通过，0 失败、0 跳过 | 7 类场景整轮通过 | 6/6 |
| 0.2.1-alpha.2 | 393 通过，0 失败、0 跳过 | 前 6 类通过；草稿取消在独立 profile 按下述补充指令补验通过，分轮覆盖 | 原轮 5/5，补验 2/2 |
| 0.2.1-alpha.3 | 393 通过，0 失败、0 跳过 | 7 类场景整轮通过 | 6/6 |

7 类场景包括基础 UI、API、固定失败 API、CSV 参数化、GitLab Markdown API、筛选 UI 和原生草稿取消。固定预期为失败的场景仍产出 FAIL，验证成功表示结果符合冻结预期。通过场景均校验原始报告重放、手工资料导出，以及 Agent 空闲、测试作用域关闭、在途工具为零；草稿取消必须通过原生取消返回，不允许补导航完成验收。

模型请求原始 session/header 记录确认使用 `opencode-go/deepseek-v4.1-flash`；请求密钥从环境读取，压缩会话中未发现本轮使用的环境密钥。三个版本的最终安装与 RunBridge 实测使用同一候选摘要，未因宿主重建发行产物。

首次矩阵将输出设在仓库忽略目录，三个宿主均在“隐藏 SDK 后应导入失败”的反向检查被拒绝：Node 会向上解析到本仓开发依赖。该轮没有进入模型或 GitLab 执行，宿主全部停止；失败记录完整保留。随后使用仓库外 `/private/tmp/dsh-runbridge-0.13.2-20261020/` 的全新目录重跑，继续使用相同包摘要，不能把首次失败记成通过。

仓库外 alpha.2 的首轮 UI 已通过，但普通聊天检查等待超时。失败截图显示模型实际回复“兼容检查已完成。”，旧脚本只接受“兼容检查完成”。本轮仅将 `scripts/compat/real-model.mjs` 的匹配扩为允许这个同义表述，仍要求实际 Agent 空闲后才继续；固定业务预期、报告证据、GitLab 持久化和资源检查保持原标准。原失败状态保留，随后在新的仓库外 alpha.2 目录完整复验。该脚本不进入发行包，候选摘要未变。

alpha.2 完整复验的前 6 类场景通过，最后草稿取消因模型没有完整原样通报计划，步骤定义被守卫拒绝，后续收尾未完整结算，原结果为 ERROR 且资源隔离；原轮汇总继续保留 FAIL。该问题属于既有模型通报及收尾路径，本轮没有扩大 RunBridge 修复范围。

为补齐草稿验收，使用同一候选包、新的独立 profile 和新种子执行 `gitlab-draft`。通过真实会话补充指令，要求先读取 test_current、将计划 Markdown 全文逐字通报后继续原用例；未修改原用例、冻结业务预期、步骤守卫或严格取消门禁。该轮草稿取消 PASS，报告、手工导出、资源释放及最终持久化均通过；卸载后 Web 与既有 MCP 正常。此结果仅记为有补充指令的分轮受控验收，不将原轮改判，也不声称 alpha.2 无补充提示整轮通过。

alpha.2 原轮另行核对关闭工单的固定种子、数量与状态匹配，草稿查询为空；原 ERROR 仍保留。三版及补验共准备 8 个专用项目，完成后全部清理，并通过登录会话逐个确认 GET 返回 404。最终验收相关 19 次宿主停止均确认进程退出；此前被门禁拒绝的轮次也已停止。

## 证据与交付边界

原始证据保存在忽略目录 `.local/runbridge-0.13.2/`：完整回归、浏览器专项日志、包逐文件检查、秘密扫描、文档检查、同页 PNG、RunBridge 事实与进程停止记录。`summary.json` 汇总实际结果，alpha.2 单独标注 `PASS_COMPOSITE_SCOPES`。`matrix-root.json` 与 `alpha2-retry-root.json` 指向仓库外 SDK、安装锁及原始宿主证据目录；`evidence/` 保留三版报告、截图、运行记录和压缩模型会话副本，alpha.2 的 `core-and-api/` 与 `draft-supplement/` 分别保留原 FAIL 和补验 PASS。清理证明见 `cleanup-proof.json`，原轮持久化补查见 `alpha2-original-persistence.json`。访问文件、认证 URL、账号、模型密钥和原始手工资料均不入 Git。
