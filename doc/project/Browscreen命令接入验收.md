## 实现范围

- 预览统一调用本机 `browscreen` 命令，支持宿主 PATH 和完整可执行文件路径。
- 删除项目目录字段、源码环境检查、uv 启动及外部服务隐式复用，没有旧配置兼容或迁移分支。
- 设置页主动检测版本，不保存配置或启动采集。运行时检测和启动等待当前有效 CDP，浮窗等待有效首帧。
- 版本查询 5 秒、启动至首帧 60 秒；失败不随进度轮询无限重启，提示只属于设置或当前浏览器测试。

## 部署与验证边界

本机已通过 uv 的独立工具环境安装 Browscreen 0.2.1，裸命令查询成功。用户当前 DSH 的插件更新及重启被自动审批审查要求另行明确授权；在获准并完成复核前，不将隔离 profile 的结果描述为该环境已更新成功。

App 场景只验证没有浏览器资源/CDP 时的展示规则，没有增加 App 自动化适配器。当前一个插件实例仍串行使用共享浏览器，多页面不自动选择目标，多对话独立并行仍为后续优化。真实业务验证使用受控本机夹具，不以外部网站内容的稳定性作为本轮通过条件。
