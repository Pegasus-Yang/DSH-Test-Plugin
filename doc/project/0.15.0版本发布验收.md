# 0.15.0 版本发布验收

日期：2026-10-24（Asia/Shanghai）。状态：本轮冻结发行包、三版宿主（含 alpha.1 分阶段补验）、真实服务及清理门禁全部通过，按项目约定本地提交并创建附注标签；提交与标签不推送。

## 交付范围

插件适配 RunBridge 整 Node 使用权租约，最终配套实测为 Hub 0.9.1／Node 0.8.1；该合同从 Hub 0.9.0／Node 0.8.0 引入。Hub／Node 的改造和发布由对应项目负责，本仓库只提交插件。前置 0.14.1 提交与标签保留。

现成访问文件继续支持 JSON 与带注释 YAML；新增明确的 Hub 自动领取来源，Hub 私有文件只含 hub_url、hub_token，目标 Node ID 与可省略的整批租期在设置页单独配置。不猜测两类文件，不在界面录入或回传原始令牌。界面展示、复制和下载使用对应的 YAML 模板。

规划、原生审核及设置检测只读工具目录，不领取 Node；批准和宣告后，首个可信浏览器初始化才领取。实际连接再与同源 MCP 声明核对。纯 API 不领取，同一 TXT／Markdown／CSV 批次共用原 Node 租约，逐用例独立开关浏览器。会话租期、Node 租期、工具超时分开；省略 Node 租期时由 Hub 默认及上限控制，不在插件硬编码一天上限。

首次申请身份先落盘，只接收首次签发的执行令牌。领取响应遗失或重复响应不含令牌时保留 UNKNOWN，不生成新请求接管旧步骤。原令牌用于查询、按需续租和归还；查询、续租和看画面不刷新设备空闲计时。Node 失效时停止旧任务，保留原 grant/session/request 证据。

浏览器关闭、MCP 断开和 Node 归还分别判断。整批收尾及正常卸载等待原租约 RELEASED 且 cleanup=COMPLETE 后才封存报告；PENDING／QUARANTINED／UNKNOWN 保留隔离，原业务断言不改判。自动执行文件权限为目录 700／文件 600，保存于报告目录之外，确认归还且无原隔离证据后删除；用户提供的文件不删除、不重写。恢复只使用原身份，不用 Hub 共享凭据强制回收。

包版本、运行 plugin_version、dist、中英文当前指南、安装标签、changelog 和 AGENTS.md 同步为 0.15.0；历史版本和历史验收保留。实现职责见[节点租约适配方案](../design/RunBridge节点租约适配方案.md)，当前操作见[RunBridge 使用指南](../user-guide/RunBridge远程浏览器与持续预览.md)。
