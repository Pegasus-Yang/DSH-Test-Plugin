# 文字规划与中文对话验收

执行者：Pegasus-Yang。日期：2026-10-04（Asia/Shanghai）。版本：0.5.0。

## 当前行为

- 自然语言规划只提交名称、简短拆分思路、业务动作短句及文字检查点，不要求模型预先填写工具、选择器、输出类型或比较器。进入当前步骤后，才根据实际页面或响应确定操作与采集方式，并绑定可复算的断言。
- `/test-plan` 继续使用同一会话的原生 plan 模式，允许要求修改，批准后执行；`/test` 通报计划后直接执行。两种通报均包含原始任务、简短拆分思路和步骤清单。首次任务原文独立保存，后续修改意见作为补充来源，不覆盖原文。
- 通过宿主公开 settings 服务读取显式语言偏好；未设置时根据用户任务语言选择中文或英文。提示覆盖简短分析摘要、进度、工具说明、追问和最终回复。浏览器自动识别的界面语言未传到 Host 时，使用任务语言回退；不声称能够读取所有客户端的自动语言状态。
- 原始文字计划保持不变；运行时步骤定义、采集修正及断言绑定另外记录。所有文字检查点在执行前预留为必需项，缺失绑定不能形成 PASS；后续新增检查点不能占用这些标识。
- 标量预期通过 `expected_value` 传递普通文字，如 `agent`、`200`、`0`；数字按文字条件或实际值类型解析，避免将点赞数字比较误降为字符串比较。对象、数组等复合预期使用 JSON。简单数字条件有确定性语义校验，但不宣称完整自然语言语义证明。
