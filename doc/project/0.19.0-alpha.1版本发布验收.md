- 设置拆为工具接入、实时画面、环境与报告，详情按需展开、连接和媒体独立保存；旧字段按原语义迁移。旧 DOM 采集可以绑定实际来源读取工具，保留冻结目标和业务预期。

## Selenium 与真实媒体

独立 Selenium MCP 服务使用原始工具，宿主中没有安装 Playwright MCP，也未提供 RunBridge。以下使用策略调整前的实测包和真实浏览器；其 125 个运行产物与最终包相同，不将旧摘要冒充最终包实测，也不以本地替身代表实机结果。

| 场景 | 结果与证据 |
| --- | --- |
| 原生名称、改名改参、无媒体／关闭能力、显式资源合同 | 四种模式的 Markdown 用户入口均通过；实际按钮只点击一次、数值为 1，程序断言、报告、账本重放、手工 MD 下载及结束状态已验证 |
| 固定反例 | 内部冻结计划只点击一次，预期仍为 2、实际为 1，报告正确为 FAIL；没有改写预期或放宽类型比较，原 Selenium 会话已真实关闭 |
| 未知媒体 | Markdown 场景有真实 Agent 尝试，另以 MiniMax M3.1 Flash 验证有效单次截图；混合来源场景从 Selenium 实际取得 7 帧并验证定时截图 |
| 更名 Playwright 默认适配 | 业务 PASS、实际点击一次，取得 3 帧，验证单次和定时截图；不重启或关闭共享连接 |
| 显式 Playwright CDP／Browscreen 录像 | 业务 PASS、持续画面 52 帧；报告播放及视频下载摘要一致 |
| RunBridge | 业务 PASS、持续画面 110 帧；原 Node 归还为 RELEASED |
| 三来源组合 | Playwright、RunBridge、Selenium 三条用例全部 PASS，实际点击共 3 次；分别观察到 75、150、7 帧，画面跟随实际来源；原 Node 归还为 RELEASED |

媒体专项使用内部冻结 JSON 计划隔离媒体与模型业务规划，Markdown 用户入口由 Selenium 四模式和 GitLab 另行验证。单次图片、定时截图和持续通道不能互相替代；只有截图不代表支持录像。自建 RunBridge 测试池最终为 UNCLAIMED、浏览器 FREE，自有 Hub／Node 进程已停止。Selenium 服务是测试夹具，完成后自行退出并核对原会话，插件不因品牌自动关闭外部共享上下文。

## 失败记录与能力边界

开发与正式验证过程中出现过模型提交无效范围格式、把文本 `"1"` 与数值 `1` 比较、声明的采集来源或文本分隔与实际返回不符、偏离一次点击约束的轮次。它们保持 ERROR／FAIL 或被独立验收脚本拒绝，不反推预期、不修写原记录。复验使用新环境和相同种子；安装包不因这类模型规划失败而放宽校验。模型能够选择工具不等于任意轮次都能生成正确计划。本次不作为全部真实模型门禁通过的正式发布验收，也不自动合入 main。

未知协议不一概支持：只有实际调用能证明原页面并取得受支持图片／通道时才发布画面。普通 MCP 检测只读宿主工具注册状态，不伪称完成新的网络握手；登记、连接和当前对话可见性分别表达。业务必需能力缺失仍按原用例报告未完成。

本机原始日志和试包位于忽略目录 `artifacts/generic-0.19.0-alpha.1/`；最终包两版本摘要、运行记录和停止证明归档在其 `final-evidence/`；Selenium 与媒体证据在 `verified-evidence/`，策略变更前的模型失败记录保留在 `final-evidence/previous-attempts/`。设计过程材料位于 `artifacts/design/tool-connections-2026-11-01/`。真实输入、手工资料和临时访问地址仅在本机，不进入 Git。
