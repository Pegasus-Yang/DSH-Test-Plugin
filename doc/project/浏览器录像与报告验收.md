# 浏览器录像与报告验收

验收日期：2026-10-05，Asia/Shanghai。插件基线 `a6b2605`，包版本仍为 `0.9.2`；本次为未发布更新，不创建新版本或标签。依据[已批准实施方案](../design/Browscreen视频录制与报告接入实施方案.md)完成实现。

## 交付行为

- 设置新增“录制浏览器操作视频”，独立于实时预览，默认关闭；四个测试命令共用保存的设置。
- 实际浏览器资源与当前唯一页面 CDP 就绪后才启动，录像有服务端轮询，不依赖前端请求；纯 API 不启动采集、不生成录像字段。
- 每个采集进程保存独立的运行/实例片段，按摘要、MP4 索引和文件检查结算，再计算 SHA-256。正常报告等待归档；紧急封存后不允许迟到结果覆盖状态。
- 报告条件显示“操作录像”，支持播放、拖动和下载；原始及重建报告引用同一批独立 MP4。接口实例不显示媒体入口；纯接口报告无截图对话框。
- 缺命令、版本不支持或缺 PyAV/libx264 时按需提示。录制准备失败且预览开启时，只回退一次预览启动；不自动安装依赖，不修改业务断言或解除隔离。

当前模块、字段和访问规则见[当前实现](../architecture/当前实现.md)，安装与操作见[浏览器录像与报告](../user-guide/浏览器录像与报告.md)。

## 自动回归

公开 SDK 环境类型检查、构建及包入口检查通过；**195 项单元测试 + 33 项集成测试，共 228 项通过**。测试覆盖：

- 四种开关组合、默认关闭、稳定版本范围、命令缺失/超时及本机路径解析。
- 无前端请求的后台启动、API 不启动、实例片段隔离和一次依赖失败回退。
- UTF-8 分片摘要、完整/部分/无帧/失败、MP4 检查、哈希归档及紧急封存后迟到结果拒绝。
- 收尾可超过旧的 1.5 秒限制；超过剩余清理预算则强制结束并记录录像 FAILED。
- 条件播放器、混合实例切换、纯 API 无媒体、取消/部分片段及缺文件提示。
- MP4 流式读取、单段 Range、HEAD、416、路径边界、下载附件响应与文件专用票据限制。
- 既有当前 Agent、可信采集、断言、计划审核、取消和必要清理链路回归。

提交的 `tests/fixtures/minimal.mp4` 为 1 秒纯色块合成文件，没有真实界面或个人数据；原始验收视频不进入 Git。

## 实测发现与修复

初次混合批次已正常归档和播放，但下载事件未触发。报告既有 opaque sandbox 会影响严格 Cookie 及跨来源下载属性。实施补充保留 sandbox，只在已认证 HTML 响应里签发一个 MP4 的 HMAC 只读票据，并为下载链接返回 `Content-Disposition: attachment`。随后使用真实报告重新验证播放、拖动、下载和离线目录；初次失败记录保留在本地。

自动验收脚本还遇到页面初次加载尚未完成、重复“新建会话”按钮以及已保存配置不可再次保存等定位问题。修正脚本等待及选择方式后完成验收；未以脚本错误推断产品成功。解码使用 PyAV 的原始 RGB 平面，额外的 NumPy 不是插件录像依赖。

## 交付核对与边界

`dist` 的 79 个文件与独立公开 SDK 构建逐字节一致。最终安装包核对所有入口与 `dist`，不包含 `.local`、凭据、原始运行、真实 MP4、测试夹具或本机绝对路径依赖。普通本地 tgz 通过公开 CLI remove/add 后启动独立 npm 宿主，设置、执行和报告均正常，不需要 `link-host`。

本轮真实验证本机 Chromium/CDP、单活动页面、静态 GET JSON 和 H.264 报告。部分录像、写入失败、强杀及迟到摘要主要由单元测试验证；未把这些模拟场景称作真实端到端验收。没有新增 App 测试、录制非 CDP 界面、多对话并行或无模型回放。

本轮自建服务在验收结束后停止；用户 3080 服务保留。改动仅创建本地提交供审核，不推送，不打新标签；变化列入根目录 `changelog.md` 的“未发布”。原始日志、认证地址、截图、下载和验收结果保存在忽略的 `.local/video-implementation/`，用户模型凭据未进入公开文档。
