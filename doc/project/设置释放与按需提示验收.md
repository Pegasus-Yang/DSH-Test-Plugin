# 设置释放与按需提示验收

日期：2026-10-04。版本：0.8.2（开发版本）。本次将 0.8.1 的普通对话常驻隔离提示改为按需提示，并将环境处置入口放到设置中；不修改 DSH 核心或既有释放规则。

## 当前行为

1. 普通对话不挂载隔离面板、不请求 `/test-recovery`。安装插件但没有调用测试功能的用户不收到全局隔离提醒。
2. 客户端监听宿主公开 `command/executed`，仅处理本插件九个命令的回执。错误只展示在发起命令的会话中，可手动关闭；测试命令成功或设置释放成功后清除。刷新页面不恢复全局常驻提示。
3. 测试启动被隔离阻塞时，明确引导“设置 → 测试插件 → 测试环境”，确认旧操作停止、处理并释放，再重新执行。新测试没有开始，插件不自动重试。
4. 设置页显示就绪状态，或隔离原因、持续时间、超时阈值及遗留运行。释放仍需先勾选确认；失败保留隔离，取消和读取状态不会释放资源。
5. 设置操作经当前显示对话的原生命令执行，保留工具审批。没有当前对话时提示先打开一个对话；不会借用其他会话的 Agent。

## 自动验证

`node node_modules/vitest/vitest.mjs run tests/unit tests/integration`：16 个文件，138 项通过；`node scripts/build.mjs`：TypeScript 声明与浏览器端构建通过。

新增回归覆盖普通会话没有隔离查询/释放入口、非本插件命令不触发提示、两个会话提示互不传播、关闭提示不发送释放命令、成功清除提示、设置读取不释放、释放失败保留提示，以及释放使用操作时的当前会话。真实 Cordis 依赖边界验证保留，防止普通对象替身掩盖遗漏 `remote.commands` 注入。

## 真实页面验证

使用独立 home、13411 端口和独立输出目录，专用 Playwright MCP 实际打开本地夹具页面，再生成明确标注“本地验收模拟”的历史隔离。没有调用模型；没有冒充正式社区业务测试。

| 检查 | 结果 |
| --- | --- |
| 有隔离、尚未提交测试命令 | 普通空白对话没有隔离面板或命令提示 |
| 发送 `/test` 社区用例描述 | 立即出现当前会话提示，包含设置路径与重新执行指引；没有开始业务执行 |
| 打开设置中的测试插件 | 显示隔离原因、持续时间、超时阈值和“处理并释放” |
| 未勾选确认 | “确认关闭并释放”不可点击 |
| 取消 | 隔离文件仍存在，处置记录为零，旧结果不变 |
| 勾选并确认 | 原生 `mcp__playwright__browser_close` 成功，预览收尾已确认，保存一条处置审计并解除隔离 |
| 释放完成 | 设置显示成功及重新发送指引；会话提示清除，旧测试仍是 ERROR，原结果内容逐字不变 |

会话之间的提示隔离由自动回归直接验证两个不同 session ID。宿主会复用没有聊天正文的空白草稿；在该草稿点击“新建会话”没有创建另一条会话，因此不将此操作计作不同会话的真实 UI 验收。

本地证据位于忽略目录 `artifacts/validation/recovery-settings/`：`ordinary-chat.png`、`blocked-command.png`、`settings-confirmation.png`、`released.png` 与 `verification.json`。确认界面已同步到用户指南。旧 0.8.1 验收记录按原事实保留，当前入口以本文件和用户指南为准。

## 安装包与用户环境

安装包包含 88 个文件，没有 `.local`、`artifacts`、测试或依赖目录。用户默认 Web profile 经 DSH 公开 CLI 更新为 0.8.2，前端及服务端安装文件摘要与本地构建一致。实际 3080 页面已验证普通对话没有提示，设置页显示“测试环境已就绪，无需释放”，原有预览偏好仍在。

更新前后的 profile 设置摘要相同；核对时用户环境已经没有 `quarantine.json`，更新后保持该状态。本次没有替用户确认或释放真实资源。3080 服务正常重启后的 PID 为 19145，沿用后台运行方式；认证地址及日志路径仅记录在忽略的 `.local/user-dsh-recovery-state.json`，日志在 `.local/user-dsh-settings.log`。安装核验和实际截图保存在 `install-verification.json`、`user-ordinary-chat.png`、`user-settings.png`。

## 验证边界

本次验证提示展示与既有恢复链路，不重新执行 `ceshiren.com` 业务用例，也不实现多对话并行浏览器。真实用户 profile 的环境状态仅核对，验收释放只针对独立实例的专用浏览器与模拟隔离。
