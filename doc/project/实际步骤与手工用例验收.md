## 交付行为

- 当前测试作用域注册内部 `test_execute_operation`，保存简短操作说明后，沿用同一 Agent 的工具管线转交原 Playwright 工具。原生观察与可信采集继续使用原入口，四个斜杠命令保持原用途。
- 身份、顺序、归属、派发和结算由程序保存。成功、错误、拒绝、未知与迟到结果分开；同名重试保留，每个用例/数据实例分别编号。准备和业务收尾另列，自动复位、关闭不占业务编号。
- GET 的每个真实采集子请求记录一次说明；检查直接投影原 `AssertionResult`。实际输入来自脱敏调用，预期来自原检查。未定义的中间预期保留为待补充。
- 报告新增实际步骤及当前实例/批次下载，保存 `actual-steps.json` 和 `manual-cases.md`；只读重建生成带 `-rebuilt` 的文件，原文件保留。旧记录不补写说明，接口实例不出现媒体入口。

## 验证环境与证据边界

构建使用公开 npm DSH SDK `0.2.1-alpha.1`；真实运行使用独立安装的 `@deepseek-ai/dsh@0.2.1-alpha.1`、专用 `@playwright/mcp@0.0.68`、Browscreen `0.3.0` 与视频依赖。宿主 `13429`、采集 `13430`、搜索夹具 `13431` 均仅绑定本机。所有测试使用隔离 profile、专用用例目录和自有浏览器，没有安装或重启用户的 DSH profile。

运行、私有访问地址、原始账本和 MP4 保存在被忽略的 `.local/actual-operations/` 及隔离工作区，不进入 Git 或插件包。文档图片仅包含本机夹具报告。编译和生命周期替身回归与真实宿主/模型执行分别核对，不以替身测试代替真实网页验收。

## 导出、布局和录像

- 实际步骤 JSON 与 Markdown 的实例下载可用；Markdown 转义特殊字符，临时定位参数保留在调用依据，实际输入使用可读参数。失败说明可能仍涉及临时引用，保存为手工用例前按“需复核”处理。
- 原/重建接口文件及最终自然语言用例的JSON/Markdown均逐字节一致；重建只读取账本。在线认证 GET/HEAD 文件路由及 Markdown 附件响应正常，报告的 sandbox 保持原策略。
- 真实混合报告的 390px 窄窗口没有整页横向溢出。长说明和输入按区域换行，选项卡可横向滚动。
- 混合录像原报告、重建报告、两种离线报告均播放和拖动成功，下载 SHA-256 与归档一致，HTTP 返回206。切换到接口实例时暂停旧视频、回退实际步骤，接口没有媒体入口。
- 助理读取保存的 Markdown，按可见搜索按钮、文本框、提交按钮和结果链接逐项走查夹具，正文非空；没有解释执行导出JSON或复用MCP ref。这是文档可用性走查，未声称由真人完成或形成无模型自动回放。

## 验收中修正的两处问题

1. 模型把“正文不为空”绑定成 `neq "0"`，这不能验证非空。增加正文/文本非空校验，要求可信文本与空字符串比较；空正文反例为FAIL，原预期正确保留在导出中。
2. MCP在原生停止时可能返回普通取消错误，没有标准错误码。操作结算同时查看原生取消信号；已派发且受取消的结果标为UNKNOWN，不依赖错误文字。取消前已结算操作保留原状态，封存后的迟到结果只审计。

最终直接/test复测总耗时89.5秒，5条业务操作对应5次封装和5次原生子调用；没有无效封装请求。与前面的混合初验不是相同输入的性能A/B比较。

## 成本与适用范围

每个带说明动作增加一个插件封装调用和一个原生子调用；没有单独“登记说明”的模型轮次。输入并提交、多字段填表拆开后，业务工具及模型轮次可能增加。实测隐藏夹具总耗时59.6秒、显示夹具69.6秒、网站163.5秒、GET接口21.1秒、CSV52.8秒、混合248.4秒；包括模型、审批和文件读取，未做相同输入的旧版A/B基准。该混合初验中5个浏览器实际动作对应24次封装请求，19次因模型省略MCP前缀在入口校验阶段失败，没有派发到浏览器。交付前将完整名称加入Schema枚举，并明确错误提示，防止反复猜测短名称；运行时还校验description、tool_name、arguments，拒绝缺失字段及模型声明状态。常规交互指导明确要求逐动作工具；无法用原子工具表达的脚本仍保存一条复合记录并需复核。最终用例复核见下方补充。原执行预算未增加。

说明语义仍依赖模型；脚本内部动作不自动拆分或保证逐项成功，完整性与业务PASS/FAIL分开。当前接入范围为专用 Playwright MCP 和可信 GET JSON，未新增本地CLI/App适配、理想路径整理、自动脚本生成或回放能力。生命周期替身覆盖强制截止、迟到和写入失败；真实拒绝、定位错误和停止分别核验。
